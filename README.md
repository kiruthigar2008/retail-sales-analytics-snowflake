# Retail Sales Analytics Dashboard

## Project Overview
An interactive retail sales analytics project built using Snowflake SQL. The dashboard helps analyze sales performance, product revenue, customer spending, and daily revenue trends.

## Tools & Technologies
- Snowflake
- SQL
- Snowflake Snowsight Dashboards

## Key Performance Indicators
- Total Revenue: ₹17,450
- Total Orders: 10
- Average Order Value: ₹1,745
- Total Units Sold: 21

## Dashboard Features
- Product-wise Revenue Analysis
- Customer Spending Analysis
- Daily Revenue Trend
- KPI Scorecards

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions: SUM, COUNT, AVG, MAX, MIN
- Views

## Key Learning Outcomes
- Creating and managing tables in Snowflake
- Writing SQL queries for business analysis
- Calculating business performance metrics
- Creating visualizations and dashboards
- Presenting data-driven insights

## Dataset
A sample retail sales dataset containing 10 order records.

## Conclusion
This project demonstrates how SQL and Snowflake can be used to transform sales data into meaningful business insights.
